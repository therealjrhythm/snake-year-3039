## Important distinctions
The five-district game is the release; the first polished district is only a development milestone. All listed launch modes, enemies, abilities, bosses, progression and presentation belong to the full release. Proposed names, counts and balance values remain open to documented iteration.

This is a specification package. It does not contain a runnable game, production 3D models, separated textures, finished UI, sound assets, or fonts. Benchmarks, gameplay tests and physical-controller compatibility have not yet been performed. Do not use the previous package as the active release brief.
